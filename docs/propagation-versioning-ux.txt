- Same owner means your code for now; a project boundary can replace that later.
- Editing your code automatically updates callers under the same owner.
- The cascade stops at another owner, including transitive callers.
- External library calls keep the exact versions selected when saved.
- deps <caller> shows those references and whether newer branch versions exist.
- deps upgrade <caller> <dependency> upgrades one selected dependency.
- That upgrade updates the caller and its same-owner callers, not other consumers.
- Branch upgrades stay on the branch; main and sibling branches stay unchanged.
- undo restores a previous version without changing future update rules.
- Remove pin/follow modes, module policies, and the propagation toggle screen.
- Permission approval remains a separate decision about code and authority.
- Keep summaries short; inspect deps and status for the detailed changes.
- Historical content stays addressable by its hash.
