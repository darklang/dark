# Compiler coverage, 2026-09-17-upstream

Which package fns the native compiler compiles, which it doesn't and why, and of
those that compile, which provably agree with the interpreter on synthesized
arguments. Generated by `scripts/compiler/report`; the `.tsv` beside this file has
every fn.

"Compiles" means the fn and its whole closure, pretty-printed as Dark source, went
through the compiler's front end, checker and lowering without an error. "Match"
means the compiled binary and the interpreter produced the same JSON for the same
synthesized arguments; "noargs" means the harness could not write arguments (a
custom-typed parameter it cannot build), which says nothing about correctness
either way. Stdlib fns are the compiler's own implementations, called from the entry.
