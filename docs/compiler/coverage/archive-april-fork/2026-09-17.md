# Compiler coverage, 2026-09-17

Which package fns the native compiler compiles, which it doesn't and why, and of
those that compile, which provably agree with the interpreter on synthesized
arguments. Generated by `scripts/compiler/report`; the `.tsv` beside this file has
every fn.

"Compiles" means the bridge lowered the fn and its whole closure and the compiler
emitted an ELF. "Match" means the compiled binary and the interpreter produced the
same wire bytes for the same synthesized arguments; "unprovable"/"noargs" means the
harness could not build arguments (a function-typed or custom-typed parameter),
which says nothing about correctness either way. Authored cases (CompilerCases) will
replace synthesized arguments as they land.
