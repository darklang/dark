Darklang in the browser

The real Dark CLI, runtime and package store, compiled to WebAssembly. Everything runs in this tab; nothing is sent anywhere. First load is ~25 MB.

  • Workbench cli.html
    What dark opens: the package tree, docs, changes, a REPL workspace. A shell on the right takes dark <command> lines against the same store.
  • Workbench, full width cli.html?panel=0
    The same, without the shell.
  • Classic prompt cli.html?env=DARK_CLASSIC=1
    The inline prompt instead of the workbench: help, ls, eval 1 + 2, quit.
  • REPL repl.html
    One expression at a time over a package snapshot. The older, smaller page; no store, no CLI.

A URL is a place in the CLI

  • Run a command cli.html?cmd=eval+1+%2B+2
    Runs it, then hands you the prompt. ?cmd=search+map, ?cmd=docs+syntax, ?cmd=ls+Darklang.Stdlib.List.
  • Land on a function cli.html?fn=Darklang.Stdlib.List.map
    Sugar for ?cmd=view+<name>.

Per tab and in memory: reload and the store is fresh. Sync verbs are there but no relay is configured, and no secret ships with the page.
